# مسيراتي

تطبيق ويب لحساب وتتبّع إحصائيات المسيرات (القادة، المعدات، السلاح، المواهب، التشكيل، النقوش) للعبة رايز.

## تشغيله محلياً (على الكمبيوتر، للتجربة)

يحتاج [Node.js](https://nodejs.org) مثبّت عندك.

```bash
npm install
npm run dev
```

بعدها يفتح لك رابط محلي (عادة `http://localhost:5173`) تفتحه بأي متصفح.

## رفعه على GitHub ونشره كموقع (عشان تستخدمه بالآيباد)

### 1. ارفعه على GitHub
```bash
git init
git add .
git commit -m "أول نسخة"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### 2. غيّر اسم الريبو بملف الإعدادات
افتح `vite.config.js` وغيّر السطر:
```js
base: '/masirati/',
```
لاسم الريبو الفعلي عندك (لازم يطابق بالضبط، حساس لحالة الأحرف). نفس الشي بملف `public/manifest.json` (السطرين `start_url` و`icons.src`).

### 3. فعّل النشر التلقائي (GitHub Actions) — ما يحتاج Node ولا Terminal
الملف `.github/workflows/deploy.yml` جاهز مسبقاً — يبني وينشر الموقع تلقائياً في كل مرة ترفع فيها تحديث للفرع `main`، بدون ما تحتاج تثبت أي برنامج أو تكتب أوامر.

كل اللي عليك: من إعدادات الريبو بـ GitHub (Settings → Pages)، تحت "Build and deployment" اختر Source = **GitHub Actions**. بعدها أول Push (أو رفع ملفات) بيشغّل النشر تلقائياً — تقدر تتابعه من تبويب **Actions** بالريبو.

بعد كم دقيقة، موقعك يصير شغال على:
```
https://USERNAME.github.io/REPO_NAME/
```

### 4. ضيفه على الآيباد كتطبيق
1. افتح الرابط أعلاه بمتصفح **Safari** بالآيباد (لازم Safari تحديداً، مو Chrome).
2. اضغط زر المشاركة (المربع مع السهم لأعلى).
3. اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. بعدها بيظهر أيقونة على شاشتك الرئيسية تفتح التطبيق بواجهة كاملة (بدون شريط عنوان المتصفح)، وكأنه تطبيق حقيقي.

## ملاحظة مهمة عن حفظ البيانات

التطبيق يحفظ بياناتك (المسيرات المحفوظة، بيانات القادة) محلياً على جهازك عبر `localStorage`. هذا يعني:
- البيانات **تبقى محفوظة** حتى لو أغلقت المتصفح أو أعدت تشغيل الآيباد.
- البيانات **مرتبطة بالجهاز والمتصفح** — لو فتحت نفس الرابط من جهاز ثاني أو متصفح ثاني، ما تلقى بياناتك (كل جهاز له نسخته المستقلة).
- لو مسحت بيانات Safari (Clear History and Website Data)، بتفقد كل شي محفوظ بالتطبيق.

## البنية

- `src/App.jsx` — كل كود التطبيق (المكونات، الحسابات، البيانات الثابتة للقادة والمعدات والنقوش).
- `src/main.jsx` — نقطة الدخول (تشغّل React).
- `index.html` — الصفحة الأساسية + إعدادات "إضافة للشاشة الرئيسية".
- `public/manifest.json` — إعدادات التطبيق كـ PWA.
